# Cinema Club Tracker

Учебный бэкенд на FastAPI для закрытого клуба кинолюбителей. Участники смогут находить фильмы, оставлять оценки и отзывы, а также сравнивать рейтинг клуба с внешними рейтингами.

**Статус:** подготовлено [техническое задание](TECHNICAL_SPECIFICATION.md). Приложение, тесты и CI пока не реализованы. Инструкции запуска, проверки и диагностики будут добавлены вместе с работающим кодом.

## Возможности по ТЗ

- Регистрация по приглашению, вход и восстановление пароля.
- Поиск и подбор фильмов, загрузка описаний, актёров, режиссёров и внешних рейтингов через API.
- Собственный каталог клуба и одна изменяемая запись с оценками и/или отзывом от каждого участника на фильм.
- Отзывы доступны участникам клуба без раскрытия автора.
- Средние оценки клуба и отдельные счётчики оценок и текстовых отзывов.
- Проверка работоспособности через `/health`, версия через `/version`, документация Swagger.
- CI в GitHub Actions при `push` и `pull_request`: Ruff, проверка миграций и pytest. Подробности — в [разделе ТЗ о CI](TECHNICAL_SPECIFICATION.md#112-ci-в-github-actions).

## Оценки

Каждый участник выставляет целые оценки от 1 до 10 по шести отдельным параметрам:

| Поле API | Параметр |
|---|---|
| `idea` | Идея |
| `plot` | Сюжет |
| `screenplay` | Сценарий |
| `acting` | Игра актёров |
| `sound` | Звук |
| `visuals` | Визуал |

Общая оценка рассчитывается сервером как средняя взвешенная. В первой версии все веса равны 1:

```text
overall = (idea + plot + screenplay + acting + sound + visuals) / 6
```

Клубная общая оценка — среднее общих оценок участников. Запись только с текстом отзыва не увеличивает число оценивших.

## Планируемый стек

Python 3.12, FastAPI, Uvicorn, Pydantic, SQLAlchemy, SQLite, Alembic, HTTPX, PyJWT и Argon2. Автоматические проверки: pytest, Ruff и GitHub Actions. Внешний источник фильмов — Kinopoisk API Unofficial; восстановление пароля — через SMTP.

## Настройки и приватность

Настройки будут читаться из переменных окружения. Пароли, токены, API-ключи, настоящий `.env`, пользовательские базы данных и локальные письма не публикуются. Безопасный `.env.example` появится при реализации конфигурации.

Подробные сценарии, API, ограничения и критерии приёмки описаны в [ТЗ](TECHNICAL_SPECIFICATION.md).
